Agent models and effort

Bot-wide settings

Leave repository empty for bot-wide settings. Repository settings apply only to the selected repository and bot user, and persist across restarts. Save creates a complete repository override; Use bot defaults removes it. Explicit mention options take precedence.

Set the agent, model and reasoning effort for an agent user's next runs. The default model choice restores its configured agent_model; the default effort leaves the agent's own choice. Choices load from the agent’s own model catalog for this user (where supported), alongside configured and recently reported models for the same agent; choose Custom model to enter another model ID. Bot-wide agent changes reset on restart; model and effort changes are saved across restarts and do not affect runs already in progress.

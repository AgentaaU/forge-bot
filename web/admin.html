Agent models and effort

Set the model and reasoning effort for an agent user's next runs. The default model choice restores its configured agent_model; the default effort leaves the agent's own choice. Choices include configured and recently reported models for the same agent; choose Custom model to enter another model ID. Changes are saved across restarts and do not affect runs already in progress.

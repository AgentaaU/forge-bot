forge-bot notifications

Pick your human account and enable browser notifications. Web push can deliver even when this page is closed; polling requires keeping it open. Desktop browsers use the page directly. Mobile browsers require HTTPS and a service worker; on iOS 16.4+ add this page to the Home Screen first, then grant notification permission. Use Send test notification to confirm the notification appears in your system notification shade, or Run diagnostics to upload browser state for debugging.

Notifications appear here but not in the system notification shade?

On Android, open Settings → Apps → your browser → Notifications. Allow notifications for the browser and this site's notification channel. If you installed this page as an app, also check that app's notification settings. Check Do Not Disturb and any battery restrictions, then send a test notification.

Site permission and Android notification settings are separate. The browser can accept a notification while Android suppresses it; this page and its diagnostics cannot read or change those system settings.
